# Swad Mustasin Khan

Erasmus Mundus scholar in Applied Cybersecurity (CyberMACS) · Kadir Has University, Istanbul → Ss. Cyril and Methodius University, Skopje

I work at the intersection of **machine learning and security**:

- **Security of LLM-based agents:** prompt injection, memory poisoning, and misuse of tools connected through MCP
- **Privacy-preserving federated learning** for critical-infrastructure intrusion detection, measured on real edge hardware
